# TRX

## Platform
web

## Product Purpose
Aplicación personal de tareas y organización del tiempo. El usuario solicita rehacer el diseño para que sea profesional, intuitivo y llamativo, con libertad para consultar referencias.

## Capabilities and Constraints
Conservar tareas, eventos, Kanban, calendario, agenda, listas compartidas, notas, estadísticas, temporizador y Pomodoro. Conservar autenticación Supabase y modo demo. Aplicación estática HTML/CSS/JavaScript publicada en GitHub Pages, sin migrar framework ni cambiar el backend para este rediseño.

## Users
El propietario utiliza TRX para productividad. El usuario confirmó que escritorio y móvil deben recibir el mismo cuidado. La interfaz da prioridad a tareas y planificación diaria, con acceso directo a concentración.

## Brand Commitments
Nombre TRX, interfaz en español, logotipo existente. El usuario permite reemplazar el diseño actual y tomar referencias de productos similares.

## Evidence on Hand
El contexto del código, GitHub y Supabase se revisó antes del rediseño; las notas técnicas privadas no se publican. La demo existente proporciona ejemplos explícitamente identificados como demostración. No inventar integraciones, sincronización de calendarios externos o capacidades del backend.
